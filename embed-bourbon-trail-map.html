Who This Is For

We built this for the people who keep getting asked bourbon questions they didn't sign up to answer.

Short-term rental hosts

Every guest asks which distilleries are close, and almost nobody wants to build a page to answer it. You don't need a website. Embed it if you have one, or use the link and printable QR code in your welcome binder, check-in message, or Airbnb guidebook.

B&Bs, cabins, and small inns

You compete with hotels that have concierge desks. A map on your "things to do" page, or a QR card at the breakfast table, does a version of that job without staffing it.

Visitor bureaus and chambers

Nelson, Washington, Woodford, Franklin, and Anderson county visitors are mostly here for bourbon. Set the widget to your region and it becomes a county-level distillery map.

Venues, golf courses, and event spaces

Wedding parties and golf groups travel in for bourbon and build the rest of the weekend around it. Give them something to plan with while they're already on your site.

What Your Visitors Get

The widget is the same map we run on our own site, with our navigation and sign-up prompts stripped out. Inside it, a visitor can:

  • See every distillery we cover as a pin colored by region, official Kentucky Bourbon Trail stops and craft producers alike.
  • Filter by region to cut the map down to the cluster they're actually driving to.
  • Search by name and fly straight to a distillery.
  • Tap any pin for tour pricing, booking difficulty, and our rating.
  • Open the full profile for a distillery, which opens in a new tab so they never lose your page.

That last point matters more than it sounds. Every link inside the widget opens in a new tab on purpose. Nobody ends up accidentally browsing our site inside a small box on yours.

How to Install It

There is no plugin, no script tag, and nothing to configure. It is one block of plain HTML.

  • WordPress: add a Custom HTML block and paste it in. In the classic editor, switch to the Text tab first.
  • Squarespace: add a Code block and paste it in. Leave the type set to HTML.
  • Wix: Add › Embed Code › Embed HTML, then choose Code and paste.
  • Airbnb or VRBO listings: those platforms accept neither custom HTML nor QR images, so the link is your way in. Put it in your guidebook or your check-in message. The link and QR section below writes both for you.
  • Guidebook platforms (Hostfully, Touch Stay, Hospitable): use the link rather than the embed. Switch the generator to Guidebook platforms for the per-platform notes.
  • No website at all: you still have a path. Skip to the link and QR code.
  • Anything else: if the page accepts raw HTML, the embed works.
On page speed

Nobody should have to trade their Core Web Vitals for a map, so the snippet ships with loading="lazy" already on it. The widget does not load at all until a visitor scrolls near it, which means it costs a page that nobody scrolls exactly nothing.

Beyond that, map tiles load only for the patch of Kentucky actually on screen, and because the widget sits on a different domain, current browsers give it its own process so its JavaScript never blocks yours. If you'd rather it not load automatically at all, put it behind a "See the distillery map" link on a dedicated page.

Where hosts actually put it

  • The welcome binder or house manual. Print the card, slide it in a sleeve, done. This is the one that gets used most, because guests are already flipping through it looking for the wifi password.
  • Inside a cabinet door or on the fridge. Somewhere they will be standing anyway, coffee in hand, deciding what to do with the day.
  • Your check-in message. Use the guest message the generator writes for you. It reads like a host talking, not a marketing blast.
  • Your Airbnb or VRBO guidebook. Those platforms do not accept HTML or QR images, so the link is the way in. See the install notes above for the detail on that.
Printing a QR code that actually scans

Three things matter and all three are handled for you. The code is generated at a high enough resolution to stay crisp at print size. It keeps its quiet zone, the plain white border around the outside, which stops scanning if you crop it off to tidy the card up. And the link inside it is deliberately short, which means fewer, chunkier squares and a code that reads from across a room rather than at arm's length. The card prints it at over three inches square.

Grayscale is fine. So is a cheap inkjet. What kills a QR code is a laminate with heavy glare, so if you laminate the card, use matte.

Questions Hosts Actually Ask

Is it really free, and is there a catch?

It's free, and the catch is the credit line. No cost, no account, no API key, no view limit, and no expiration. We ask that you keep the small attribution link that comes with the snippet, because that link is what makes giving this away worth doing for us.

Do I have to maintain it when distilleries change?

No, and this is the main reason to use a widget instead of building your own list. It loads the live map from our site, so when a distillery opens, closes, changes its tour pricing, or gets its booking difficulty re-rated, your page is current without you doing anything. A hand-built list on your site is accurate the week you write it and quietly wrong a year later.

I don't have a website. Can I still use this?

Yes, and this is the most common situation we hear about. Switch the generator to Link and QR code and you get a link plus a printable QR card, no website involved. Full details here. Guests scan it with the camera app already on their phone.

Can I show only the distilleries near me?

Yes. Choose a region in the generator above and the widget opens already centered on that cluster. Guests can still switch regions or search the whole state, so a Bardstown host isn't hiding Louisville from anyone, just leading with what's close.

Can I change the size, border, or corners?

Yes. The height and the inline styles in the snippet are ordinary HTML and CSS, so edit them freely. Width is set to 100% so it adapts to your layout. We'd just ask you not to shrink it below about 400px tall, where the map stops being usable on a phone.

Does it work on mobile?

Yes. Below 800px the widget stacks the filter panel above the map instead of beside it, and the region legend collapses. Pinch-zoom and pin taps work the way people expect.

Do you track anything about my visitors?

We log that the widget loaded and, when the browser tells us, which domain it loaded on, so we can see where it's being used. That's it. The widget sets no cookies and writes nothing to storage on your visitors' devices, because our analytics runs in cookieless mode inside the embed specifically so you don't inherit a cookie disclosure you didn't ask for. We don't build profiles and we don't sell anything to anyone. The QR code and link carry a plain tag identifying the map as yours; there is no tracker in them.

Something looks broken. Who do I tell?

Us, please. Get in touch and tell us what site it's on and what you're seeing. We'd rather hear it from you than find out when it's been broken for a month.
